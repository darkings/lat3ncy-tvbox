# Ponyo TV 订阅源命名规范（v2 已实施）

> 目标：订阅中每条源名统一为**纯短名**（无括号、无序号、无符号），临时版与正式版一致生效。
> 状态：**✅ 已实施**（2026-08-12 09:40 CST，落地于 `generate_temp_subscription.py` / `generate_subscription.py`，已发布上线）。
> 用户确认项：无序号 / 采集站简化 / 多字品牌保留全名（3Q影视、360影视、247看）/ 撞名并存方案 A（纯短名与内置「-特性」后缀并存）。

## 1. 设计原则

全订阅统一为纯短名，与主流 TVBox 订阅风格一致（饭太硬、肥猫、多瑙……）：

| # | 原则 | 说明 | 示例 |
|---|------|------|------|
| 1 | 名字已含类型词 | 去掉方括号标签 | 包子漫画[画]→包子漫画、DJ音乐[听]→DJ音乐、番茄小说[书]→番茄小说 |
| 2 | 名字不含类型词 | 不强加标签 | 菜狗[官]→菜狗、瓜子[优]→瓜子、荐片[优]→荐片 |
| 3 | 同品牌多源需区分 | 类型词直接入名（不用括号） | 七猫短剧 / 七猫小说 |
| 4 | 采集站简化 | 去冗余词尾 + 繁转简 + 域名映射中文 | 极速资源站→极速、暴風→暴风、lovedan→艾旦 |
| 5 | 不要序号 | 全部去掉；重名靠站点归并（SITE_GROUPS）解决 | 35-最大→最大、6-非凡→非凡（归并后不出现） |
| 6 | 工具源/内置源 | 保留原名，仅字符清洗 | 豆瓣推荐 / 配置中心 / 本地视频；南瓜-多线 / Btt-秒播 |

## 2. 主名规则（采集站 / drpyS 源）

1. 去冗余词尾：`资源` `资源站` `影视` `视频` `影院` `在线` `采集` `点播` `看` `站` `网`（保留品牌核心词）
   - 极速资源站→极速、飘零资源→飘零、猫眼资源→猫眼、量子资源站→量子、滴滴资源→滴滴、火狐采集→火狐、橘猫采集→橘猫、虎牙采集→虎牙、新浪点播→新浪、如意资源→如意、光速资源→光速、红牛资源→红牛、永乐视频→永乐、飞牛影视→飞牛、枫林影视→枫林、毒舌影视→毒舌
2. 繁转简（常用字映射表）：暴風→暴风、資源→资源、無盡→无尽……
3. 域名映射中文（已知品牌）：`lovedan.net`→艾旦、`apibdzy.com`→百度；无法映射的保留清洗后短名（THZY-GH→THZY）
4. 去 `-GH` `-变体` `-采集` 等来源后缀（同站归并后无歧义）
5. 去空格、不可见字符、`┃` 等符号（沿用现有逻辑）
6. 例外：多字品牌名不强行缩短（3Q影视、映像星球、腾云驾雾、奇珍异兽、247看）
7. 删除：`(DS)` 技术标记、`[优][官][漫][画][书][听][搜][磁][采][B]` 全部方括号标签
8. 同品牌多源：类型词入名区分（七猫短剧 / 七猫小说）

## 3. 消歧（不要序号）

1. 同站多域名 → `SITE_GROUPS` 归并（樱花×3、非凡×4、红牛×2、速播×2、最大系、360 系……），每组只出一个 → 序号需求消失
2. 归并后仍撞名 → 保留各自原名差异（如 drpyS「热播」与内置「热播-多线」），不做序号补救
3. `SITE_GROUPS` 需补充：`ffzy3.tv`、`ffzy4.tv`（非凡）、`m3u8.apiyhzy.com`、`api.apiyhzy.com`、`yhzy.cc`（樱花）、`hongniuzy3.com`（红牛）、`haohuazy.com`（豪华）、`suboziyuan.net`（速播）

## 4. 安全项

- `91av.cyou`（91视频）确认为成人站 → deny（`admin:adult-content-removed`）
