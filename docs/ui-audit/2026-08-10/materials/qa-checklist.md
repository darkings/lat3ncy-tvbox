# Ponyo TV UI 验收清单

## 1. 测试环境

- [ ] 1280 × 720。
- [ ] 1920 × 1080。
- [ ] 3840 × 2160。
- [ ] 4:3 或超宽窗口兼容模式。
- [ ] 3% 与 5% overscan。
- [ ] 真实遥控器。
- [ ] 模拟器方向键与确定/返回键。
- [ ] 正常网络、500 ms 延迟、1% 丢包、断网。
- [ ] 全新安装、已有配置、配置损坏三种数据状态。
- [ ] 减少动态效果开启与关闭。

## 2. 全局视觉

- [ ] 关键内容距离左右边缘至少 64 design-mm。
- [ ] 关键内容距离上下边缘至少 32 design-mm。
- [ ] 页面没有混用荧光绿、玫红和旧蓝作为普通按钮。
- [ ] 同一页面强调色不超过 Primary 与 Tertiary 两种。
- [ ] 正文不小于 20 design-mm。
- [ ] Caption 不承担主操作或关键状态。
- [ ] 正文对比度至少 4.5:1。
- [ ] 大字和非文本焦点对比度至少 3:1。
- [ ] 所有海报保持 2:3，不拉伸。
- [ ] 缺图占位不使用品牌角色。
- [ ] URL、路径和长来源名使用中间省略。
- [ ] 720p、1080p、4K 的相对间距一致。

## 3. 焦点和遥控器

- [ ] 焦点进入反馈不超过 150 ms。
- [ ] 同一屏只有一个主焦点。
- [ ] 焦点环没有被父容器裁切。
- [ ] Focused、Selected、Pressed、Disabled 可明显区分。
- [ ] 页面返回后恢复离开前焦点。
- [ ] 列表刷新后尽量保持原项目或邻近项目焦点。
- [ ] 上下左右无死路，除非该方向确实没有内容。
- [ ] 没有无法退出的循环焦点。
- [ ] 返回键先关闭当前浮层，再退出页面。
- [ ] 删除和清空默认不会成为危险确认的初始焦点。
- [ ] 图标按钮在焦点时显示文字说明，或本身已有常驻标签。
- [ ] 所有关键 View 有可读 contentDescription。

## 4. 加载、空和错误

- [ ] 300 ms 内完成的请求不闪出 Loading。
- [ ] Loading 显示正在执行的动作。
- [ ] 3 s 后显示慢网说明。
- [ ] Loading 时仍可返回。
- [ ] Empty 有图标或角色、标题、说明和主操作。
- [ ] Error 说明用户能理解的原因。
- [ ] Error 有重试和退路。
- [ ] 技术错误默认折叠。
- [ ] 局部失败不覆盖仍可使用的整页。
- [ ] 图片失败、列表失败和播放失败使用不同文案。

## 5. Splash

- [ ] 系统 window preview 与 Activity 首帧背景完全一致。
- [ ] 品牌图标不拉伸、不裁切。
- [ ] 显示 Ponyo TV 和“今晚，选一部好片”。
- [ ] 正常启动总时长 700 至 900 ms。
- [ ] 初始化较慢时切入深色 App Shell，而不是无限停在 Splash。
- [ ] 角色最多 WAVING 一次，随后停止或进入静态。
- [ ] 转场没有白闪或黑闪。

## 6. 首页

- [ ] 品牌栏、分类栏、快捷操作和内容区层级清楚。
- [ ] 分类右侧能看出还有更多项目。
- [ ] 当前来源、当前分类和当前焦点可以同时识别。
- [ ] 快捷入口每行不超过五个。
- [ ] 海报卡只保留必要 badge、评分和标题。
- [ ] 角色不遮挡任何海报或滚动内容。
- [ ] 来源 Dialog 把工具与内容源分区。
- [ ] 来源 Dialog 恢复触发前焦点。
- [ ] 首页无内容和加载失败均有可执行操作。

## 7. 分类和筛选

- [ ] 5 列海报在 1080p 下完整显示，焦点放大不裁切。
- [ ] 评分只显示数字。
- [ ] 长榜单文案不与评分拼在一起。
- [ ] 筛选面板包含类型、地区、年份、语言、排序。
- [ ] 已选与焦点状态分离。
- [ ] 重置和应用操作可随时到达。
- [ ] 清除筛选后焦点回到合理位置。

## 8. 详情

- [ ] 海报或预览与信息区使用 5:7 栅格。
- [ ] 片名、元数据、演员、导演和简介不互相挤压。
- [ ] 原始播放 URL 默认隐藏。
- [ ] 只有一个 Primary 播放按钮。
- [ ] 次操作使用统一 Surface 样式。
- [ ] 预览默认静音。
- [ ] 预览失败不影响查看详情和选集。
- [ ] 线路、分组、排序、选集焦点路径连续。
- [ ] 已看集有明确进度。
- [ ] 无线路时可快速搜索或返回。

## 9. 点播播放器

- [ ] 成功播放画面。
- [ ] 缓冲状态。
- [ ] 暂停状态。
- [ ] 快进和快退状态。
- [ ] 拖动进度状态。
- [ ] 上一集和下一集。
- [ ] 选集与线路 Sheet。
- [ ] 倍速。
- [ ] 字幕选择和设置。
- [ ] 音轨选择。
- [ ] 弹幕设置。
- [ ] 投屏设备。
- [ ] 锁定和解锁。
- [ ] 网络中断。
- [ ] 线路失败。
- [ ] 不支持格式。
- [ ] 0 × 0、0 bps、空标题等无效值不会显示。
- [ ] 控制层不大面积遮挡视频。
- [ ] 返回键关闭顺序正确。

## 10. 搜索与聚合搜索

- [ ] 搜索范围、输入、键盘、热搜、历史和结果层级清楚。
- [ ] 字母键最小 48 × 48 design-mm。
- [ ] 热搜和历史不使用相同视觉。
- [ ] 手机输入入口能打开 QR Dialog。
- [ ] 历史删除有编辑模式和二次确认。
- [ ] 输入关键词后结果区获得更多空间。
- [ ] 搜索海报结果和文字结果均有明确焦点。
- [ ] 无结果可修改关键词或搜索更多来源。
- [ ] 聚合搜索显示“已完成/总数/结果数”。
- [ ] 可播放结果先出现即可操作。
- [ ] 单来源失败不弹全屏错误。

## 11. 历史与收藏

- [ ] 普通模式只有“编辑”操作。
- [ ] 编辑模式显示“删除所选”和“清空”。
- [ ] “完成”退出编辑，不使用语义不清的关闭图标。
- [ ] 历史卡显示时间或集数进度。
- [ ] 收藏卡显示收藏状态或更新状态。
- [ ] 来源标签不覆盖海报中心。
- [ ] 空状态有说明和去首页/搜索操作。
- [ ] 空状态不显示删除和清空。

## 12. 直播

- [ ] 正常频道播放。
- [ ] 换台提示在安全区且 1800 ms 后消失。
- [ ] 无台标时使用 icon_live，不使用品牌角色。
- [ ] 当前节目、进度、下一节目和线路信息层级清楚。
- [ ] 无 EPG 只显示一次“暂无节目单”。
- [ ] 频道组、频道和 EPG 焦点路径连续。
- [ ] 直播设置分为线路、画面、解码、EPG。
- [ ] 加载超过 3 s 显示线路尝试状态。
- [ ] 所有线路失败时可重试或选择其他频道。

## 13. 手机推送

- [ ] 显示“手机推送”标题和同一 Wi‑Fi 说明。
- [ ] QR quiet zone 完整。
- [ ] 地址可复制。
- [ ] 显示“仅局域网可访问”。
- [ ] 三步说明能在 3 米外读清。
- [ ] 推送剪贴板前说明读取内容。
- [ ] 服务未启动时有重启操作。

## 14. 本地文件

- [ ] breadcrumb 使用可理解的目录名。
- [ ] 上级目录显示“返回上一级”。
- [ ] 文件夹、视频和其他文件图标不同。
- [ ] 文件名、大小/时长和日期不互相挤压。
- [ ] 空目录有说明。
- [ ] 权限失败有授权入口和退路。
- [ ] 返回目录后恢复最后焦点。

## 15. 设置

- [ ] 左侧六个分组均可到达。
- [ ] 右侧最多两列。
- [ ] 当前分组标题和说明常驻。
- [ ] 开关项不显示 chevron。
- [ ] 单选项显示当前值和 chevron。
- [ ] 操作项显示动词。
- [ ] 完整配置 URL 不在非焦点状态暴露。
- [ ] 滚动位置可见。
- [ ] 每个分组恢复最后焦点。
- [ ] 设置变更使用非阻断式反馈。
- [ ] 清空、恢复等危险操作需要确认。

## 16. Dialog

- [ ] 20 个具体 Dialog 均有真实截图。
- [ ] scrim 为 60% 黑。
- [ ] Dialog 不越出安全区。
- [ ] 内容过高时可滚动且焦点不会被裁切。
- [ ] 初始焦点合理。
- [ ] 返回键等于取消。
- [ ] 关闭后恢复触发 View。
- [ ] 表单错误显示在输入框附近。
- [ ] 二维码保留纯白 quiet zone。
- [ ] 选项超过 8 个时可分组或搜索。
- [ ] About 显示应用版本、构建号、开源和隐私信息。

## 17. 截图交付

- [ ] 每张截图文件名与真实 Activity/Fragment/状态一致。
- [ ] 记录当前 Activity、焦点 View id、数据状态和网络状态。
- [ ] 不把桌面、系统 Splash 或上一个 Activity 误命名为目标页。
- [ ] 相同哈希截图只保留一张并标记复用。
- [ ] 每个页面至少包含 Default、Focused、Loading/Empty/Error 中适用的状态。
- [ ] 播放器和直播必须包含成功播放画面，不只交付黑屏。
